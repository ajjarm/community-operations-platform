# Community Operations Platform

A progressive web app that replaced a manual WhatsApp and Notion reporting workflow for a community organisation.

**Stack:** React, TypeScript, PostgreSQL

## Highlights

- Used monthly by 18 department heads across 14 departments
- PostgreSQL row-level security across 6 user roles
- Recurring monthly task generation and a weighted KPI engine
- Automated reports with PDF export, push reminders and calendar feeds
